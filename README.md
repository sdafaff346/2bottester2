# 🧪 봇 테스터 (Bot Tester) — SillyTavern 확장

2차 창작 봇 제작자용 테스트 도우미예요.

- **자동 테스트**: AI가 {{user}} 역할로 테스트 메시지를 대신 보내고, 봇이 답하게 해요 (턴 수 지정).
- **원작 자료 수집**: 픽시브 백과사전 · 나무위키 · 팬덤(Fandom) 위키 링크를 넣으면 본문을 긁어와요.
- **원작 일치도 평가**: 봇의 대답과 캐릭터 카드를 원작 자료와 비교해서 **퍼센트 점수**와 항목별 점수(말투, 성격, 설정, 관계, 행동), 수정할 점, 카드에 바로 붙여넣을 수정 문장을 알려줘요.

---

## 파일 구성

`manifest.json`, `index.js`, `style.css`, `README.md`, `lib/jsonrepair.mjs`가 있어요. **`lib` 폴더도 꼭 같이 넣어주세요.** `lib` 폴더가 없으면 확장이 켜지지 않아요. `jsonrepair`는 AI가 형식을 틀리게 쓴 결과를 고쳐 읽는 도구예요 (ISC 라이선스, Jos de Jong).

## 설치

### 방법 1: 폴더 복사 (제일 쉬움)
1. 받은 zip을 풀면 `SillyTavern-BotTester` 폴더가 나와요.
2. 그 폴더를 SillyTavern 설치 폴더 안의 아래 위치에 넣어주세요.
   - `SillyTavern/data/default-user/extensions/`  
     (사용자 이름을 바꿨다면 `default-user` 대신 그 이름)
3. SillyTavern 페이지를 새로고침(F5) 해요.
4. 상단 🧩 **Extensions(확장)** 메뉴 → **Manage extensions**에서 “Bot Tester (봇 테스터)”가 켜져 있는지 확인해요.

### 방법 2: GitHub에 올려서 설치
이 폴더를 GitHub 저장소로 올렸다면 Extensions → **Install extension** 에 저장소 주소를 넣으면 돼요.

## 사용법

1. 테스트할 캐릭터와 **1:1 채팅**을 열어요. (그룹 채팅은 지원 안 해요)
2. 입력창 왼쪽 **요술봉(🪄) 메뉴 → 봇 테스터**를 누르거나 `/bottest` 를 입력하면 패널이 열려요.
3. **📚 원작 자료** 탭
   - 링크를 한 줄에 하나씩 붙여넣고 **링크 불러오기**.
   - 불러온 내용은 편집할 수 있어요. 성우·굿즈·인기투표 같은 관련 없는 부분은 지우면 평가가 더 정확해져요.
   - **제작자 메모**에 “현대 AU”, “원작 이후 시점” 같이 **일부러 바꾼 설정**을 적어두면 그 부분은 감점하지 않아요.
   - 자료는 캐릭터별로 브라우저에 저장돼요 (캐릭터 카드에는 안 들어가서 배포용 카드가 깨끗하게 유지돼요).
4. **🧪 테스트** 탭
   - 턴 수와 테스트 유형(일상/원작 설정/관계성/감정 자극/가치관/돌발 상황/골고루)을 고르고 **테스트 시작**.
   - “새 채팅 열기”가 켜져 있으면 기존 채팅은 건드리지 않고 새 채팅에서 테스트해요.
   - 끝나면 자동으로 평가까지 해요. 이미 직접 대화해 둔 채팅이 있으면 **현재 채팅 평가**, 대화 없이 카드만 보고 싶으면 **카드만 평가**.
5. **📊 결과** 탭
   - 원작 일치도 %, 항목별 점수, 잘 된 점, 수정이 필요한 점(심각/보통/사소), 카드 수정 제안(복사 버튼), 카드에 빠진 원작 정보.
   - 이전 평가 기록이 남아서 카드를 고친 뒤 다시 돌리면 점수가 얼마나 올랐는지 보여줘요.

### 슬래시 커맨드
| 커맨드 | 설명 |
|---|---|
| `/bottest` | 패널 열기 |
| `/bottest-run turns=8` | 8턴 자동 테스트 (+ 설정에 따라 자동 평가) |
| `/bottest-eval` | 현재 채팅 평가 |
| `/bottest-eval mode=card` | 카드만 평가 |

## 🗣 말투·성격 검증

**말투·성격** 탭에서 봇이 원작처럼 말하고 행동하는지 언어 짝별로 검사해요. 링크는 따로 안 넣어도 돼요.

1. **캐릭터 이름·작품명**: 일본어·영어·한국어 이름과 작품명이에요. 비워두면 자동으로 채워져요. 검색 정확도에 큰 영향을 주니 한 번 확인해 주세요.
2. **① 프로필 만들기**: 원작 자료, 웹 자료, AI 지식을 합쳐서 4개 버전(🇯🇵 일본어 원작 / 🇰🇷 한국어 정발 / 🇺🇸 미국식 영어 / 🇬🇧 영국식 영어)을 정리해요.
   - 말투: 한국어 설명, 1인칭, 호칭, 격식, 어미, **사투리·억양**, 말버릇, 명대사, 하면 안 되는 말
   - 성격: 원작 캐해, 일·영·한 팬덤별 2차 캐해, 원작과 달라진 점
3. **② 언어 짝별 검증**: 버튼 3개가 따로 있어요. 프로필이 없으면 먼저 자동으로 만들어요.
   - **🇯🇵🇰🇷 일본어·한국어**: 원작 말투(사투리, 경어/반말, 1인칭)가 정발 한국어에서도 제대로 살아 있는지 봐요. 2차 캐해는 일본·한국 팬덤 기준이에요.
   - **🇰🇷🇺🇸 한국어·영어**: 존댓말/반말과 호칭이 영어에서 어떻게 표현되는지, 성격이 똑같이 느껴지는지 봐요. 2차 캐해는 한국·영어권 팬덤 기준이에요.
   - **🇺🇸🇬🇧 미국식·영국식 영어**: 두 영어에서 각각 **어떤 말투이고 어떤 성격으로 느껴지는지 한국어로 설명**해 줘요. 단어·슬랭·철자·유머 차이도 봐요. 영어 표현에는 한국어 뜻이 붙어요.
   - 결과에는 언어별 점수와 1인칭·호칭·격식·사투리·말버릇 체크가 나와요.
   - 틀린 대사는 그 언어로 고친 문장과 한국어 뜻을 같이 보여줘요.
   - 두 버전의 말투·성격이 어떻게 다른지 비교 설명해 줘요.
   - **원작 캐해 %**와 **2차 캐해 %**를 따로 보여주고, 캐붕이 의심되는 장면을 짚어줘요.
   - **🛠 지금 봇에서 고칠 부분**: 말투 문제를 없애려면 카드의 어디를(설명·예시 대사·시스템 프롬프트 등) 어떻게 고치면 되는지 급한 순서대로 알려줘요. 붙여넣을 문장은 복사 버튼으로 가져가면 되고, 고친 항목은 체크해 두면 흐리게 표시돼요. **체크리스트 복사**로 전체 목록을 메모장에 옮길 수도 있어요.
   - 결과 위쪽 작은 탭으로 언어 짝별 최근 결과를 바꿔 볼 수 있어요.
- 샘플 대사는 봇에게 언어별로 직접 받아요. 채팅에는 남지 않아요.

**커플링 언급 금지**
- 2차 캐해는 성격·습관·태도·밈만 다뤄요.
- 커플링(CP, カップリング, 受け・攻め, 夢, 커플링, "A×B", ship 등) 이야기는 자료를 모을 때부터 걸러요. AI에게도 쓰지 말라고 지시하고, 결과에 섞여 나와도 화면에 표시하기 전에 한 번 더 지워요.

**웹 검색으로 자료 보강**
- 켜두면 원작 자료 외에 필요한 자료를 자동으로 더 찾아서 프로필에 반영해요. 부족한 부분은 AI 지식으로 채우고, 항목마다 **신뢰도**(높음/보통/낮음)를 표시해요.
- 설정 탭의 웹 검색 방식에서 Serper·Tavily·SerpApi로 바꿀 수 있어요. SillyTavern에 해당 API 키가 저장돼 있어야 해요.
- 슬래시 커맨드: `/bottest-voice set=ja_ko` / `set=ko_en` / `set=en`

## 🩺 카드 진단 (v1.6)

**진단** 탭에서 카드와 로어북이 롤플레잉에 알맞게 짜여 있는지 검사해요.

1. **토큰·구조 검사**: AI를 쓰지 않아서 바로 끝나요. 진단 탭을 열면 자동으로 실행돼요.
   - 필드별 토큰(Description, Personality, 예시 대사, 첫 메시지, 상시/키워드 로어북), 매 응답마다 항상 들어가는 토큰, 컨텍스트 대비 비율을 보여줘요.
   - **금지문 과다**: "~하지 마", "절대 ~않는다", never/don't 같은 문장의 비율을 세고 예시를 보여줘요.
   - 강조어 남발(반드시·MUST·!!), 중복 문장, 카드가 {{user}}의 감정·행동을 정해버리는 문장, 너무 긴 첫 메시지·예시 대사
   - 로어북: 키워드 없는 항목, 너무 흔한 키워드, 겹치는 키워드, 너무 긴 항목, 상시 항목 토큰
2. **AI 심층 진단**
   - 롤플 적합도 %와 **GPT · Claude · Gemini별 적합도**(장점 / 위험 / 팁)를 보여줘요.
   - 고칠 점마다 붙여넣을 문장을 줘요. 금지문을 긍정문으로 바꾼 **Before → After** 예시도 보여줘요.
3. **롤플 채팅 아쉬운 점**: 현재 채팅의 봇 답장에서 아쉬운 점을 찾아요.
   - 자동 통계: 평균 길이, 질문으로 끝나는 비율, 여러 번 반복된 표현
   - 반복되는 문장 시작, 유저 대신 행동, 과한 묘사, 설정 잊음 등을 찾아서 **원인이 카드의 어디인지**와 고치는 방법을 알려줘요.
   - 테스트 탭에서 자동 테스트를 돌린 뒤에 쓰면 좋아요.
- 슬래시 커맨드: `/bottest-doctor mode=tokens` / `mode=card` / `mode=chat`
- 토큰 수는 지금 연결된 모델의 토크나이저 기준이에요. 모델끼리는 ±10~20% 정도 차이 나요.

## ✍️ 제안 바로 적용 · 🅰🅱 수정 전/후 비교 (v1.7)

**제안 바로 적용**
- 결과 화면의 수정 제안, 말투 검증의 "지금 봇에서 고칠 부분", 카드 진단의 고칠 점 옆에 있는 <i>적용</i> 버튼(📥)을 누르면 적용 창이 떠요.
- 적용할 곳(Description / Personality / Scenario / 첫 메시지 / 예시 대사 / 시스템 프롬프트 / Post-History / Character Note / 로어북 새 항목)을 고를 수 있어요.
- 내용 칸에는 **지금 카드 내용 끝에 제안을 붙인 결과**가 미리 들어가 있어요. 직접 고친 뒤 적용하면 돼요.
- 로어북은 캐릭터에 연결된 로어북에 새 항목(키워드 입력)으로 추가돼요.
- 적용 전 원본은 자동으로 백업돼요. **진단 탭 → 적용 기록**에서 언제든 되돌릴 수 있어요.

**수정 전/후 A·B 비교** (테스트 탭)
1. 테스트를 한 번 돌리면 그 테스트가 자동으로 **기준(A)**이 돼요.
2. 카드를 고친 뒤 **같은 메시지로 B 테스트**를 누르면, A와 똑같은 테스트 메시지를 새 채팅에서 다시 보내고 평가해요.
3. 결과 탭 맨 위에 A·B 점수, 항목별 점수 차이, 총평, **턴별 답장**이 나란히 나와요. ±2점은 평가 오차 범위예요.
4. B가 더 좋으면 **B를 새 기준(A)으로** 눌러서 다음 수정과 또 비교할 수 있어요.

## ✂️ 토큰 다이어트 (v2.0에서 새로 만듦)

**진단 탭 → 토큰 다이어트**에서 롤플 품질은 그대로 두고 토큰을 줄여요. SillyTavern이 프롬프트를 만드는 방식에 맞춰서 **매번 들어가는 토큰부터** 줄여요.

- **매번 들어가는 토큰**이 맨 위에 나와요. Description·Personality·Scenario·Character Note·상시 로어북은 답장마다 전부 다시 들어가서, 여기가 길수록 AI가 기억하는 채팅이 짧아져요.
- 항목마다 **매번 전송 / 상시 로어북 / 처음 한 번 / 길어지면 빠짐 / 키워드 때만** 표시가 붙어요. 처음부터 체크되는 건 매번 들어가는 큰 항목뿐이에요. 첫 메시지·예시 대사·키워드 로어북은 부담이 작아서 필요할 때만 골라요.
- **방식**
  - **압축**: 같은 칸 안에서 짧게 정리해요.
  - **로어북으로 나누기**: 말투·성격·관계·재미 장치 같은 핵심은 칸에 남기고, 장소·사건·주변 인물·아이템 같은 상황별 설정은 **키워드 로어북 항목**으로 옮겨요. 키워드가 나올 때만 들어가서 평소 토큰이 줄어요. 캐릭터에 로어북이 연결돼 있어야 적용할 수 있어요.
- 줄이는 기준
  - 없어도 캐릭터 답장이 똑같은 문장은 빼요.
  - 같은 내용은 한 번만 남겨요. 다른 칸에 이미 있는 내용도 찾아서 합쳐요.
  - 외모·좋아하는 것 같은 단순 사실은 짧은 한 줄로, 말투·행동·연출 지시는 문장 그대로 둬요.
  - 장식용 구분선(═══, ★, 이모지 줄)과 반복 제목을 지워요.
  - 예시 대사는 서로 다른 모습을 보여주는 2~3개를 남겨요.
- **재미 요소 보호**(기본으로 켜짐): 연출 지시, 트리거, 개그, 별명 규칙, 샘플 대사는 줄이지 않아요. 목표 길이를 맞추려면 이런 부분을 잘라야 할 때는 목표보다 길게 남겨요.
- 결과마다 전후 토큰, **빠지거나 합쳐진 내용**, **재미가 줄어들 수 있는 부분**, 나누기라면 **옮길 로어북 항목**(키워드 포함)을 보여줘요.
- 마음에 드는 것만 **적용**하면 돼요. 원본은 백업되고, 새로 만든 로어북 항목도 **적용 기록**에서 하나씩 되돌릴 수 있어요.
- 결과창의 **롤플 품질 지키면서 줄이는 요령**에 직접 고칠 때 쓸 팁이 정리돼 있어요.
- **원작 탭 → 요약해서 줄이기**를 누르면 긴 위키 자료를 성격·말투·관계·주요 사건 위주로 요약해요. **요약 되돌리기**도 있어요.
- 슬래시 커맨드: `/bottest-diet`
- 채팅 기록 자체를 요약하는 기능은 SillyTavern 기본 확장인 **Summarize(요약)**를 쓰면 돼요.

## 🪄 기준 스타일로 고치기 (v2.0)

재밌게 잘 되는 봇의 형식을 다른 봇에 옮겨 줘요.
1. 재밌는 봇을 열고 **진단 → 재미 분석 → 기준 스타일로 저장**을 눌러요.
2. 고치고 싶은 봇을 열고 **진단 → 기준 스타일로 고치기**에서 칸(Description, 첫 메시지, 예시 대사 등)을 골라요.
3. 고치는 정도를 골라요.
   - **살짝**: 내용은 그대로 두고 연출 지시·전환 신호·대체 행동 같은 장치만 더해요.
   - **보통**: 스타일에 맞게 구조를 다시 정리해요.
   - **과감하게**: 원래 내용을 모두 살려서 스타일대로 새로 써요.
4. 결과마다 **바뀐 점**과 전후 토큰이 나와요. 확인하고 **적용**하면 원본은 백업돼요.

원작 설정·말투·1인칭·호칭·사투리는 이 캐릭터 그대로 두고, 기준 봇에서는 **형식과 기법만** 가져와요. 적용한 뒤에는 **A/B 비교**로 실제 롤플이 더 재밌어졌는지 확인해 보세요.

## ✂️ 응답 잘림 방지 (v2.0)

- 평가·프로필·진단의 기본 최대 토큰을 16000으로 올렸어요. 설정에서 64000까지 올릴 수 있어요.
- 모델이 그만큼 큰 값을 받지 않으면 32000 → 16000 → 8192 → 4096 순서로 **자동으로 낮춰서 다시** 요청해요.
- 답이 중간에 끊기면 **끊긴 지점부터 이어서** 받아서 붙여요. 토큰 다이어트와 기준 스타일 고치기도 똑같이 이어 받아요.

## 🎭 재미 보호 (v1.9)

원작 일치도와 토큰만 보고 고치면 롤플이 밋밋해질 수 있어요. v1.9부터는 모든 기능이 **재미를 먼저 지켜요**.

- **재미 분석** (진단 탭 맨 위): 이 봇이 왜 재밌는지 형식을 분석해요.
  - 연출 지시, 모드 전환 비트, 단계별 트리거, 언어별 말투 설계, 대체 행동이 붙은 금지문, 호칭 시스템, 반복 개그, 시그니처 대사, 속마음 연출, 첫 메시지 훅 등을 찾아서 **지켜야 할 부분**으로 저장해요.
  - 저장된 부분은 수정 제안과 토큰 다이어트에서 지우거나 줄이지 않아요.
  - **이 봇의 재미 공식**을 **기준 스타일**로 저장하면, 다른 봇을 평가·수정할 때도 그 스타일을 기준으로 제안해요.
- **평가**에 **재미·몰입 점수**가 원작 일치도와 함께 나와요. A/B 비교에도 들어가요.
- 모든 수정 제안에 **재미 ↑ / 재미 ↓ 주의** 표시가 붙어요. 재미를 깎는 제안은 이유와 함께 경고해요.
- **토큰 다이어트**
  - 기본값은 "가볍게" + "재미 요소 보호"예요.
  - 연출 지시, 트리거, 개그, 별명 규칙, 샘플 대사는 줄이지 않아요.
  - 결과에 "재미가 줄어들 수 있는 부분"이 따로 표시돼요.
- **금지문 검사**: 대체 행동이 붙은 구체적인 금지문("놀라도 소리치지 않는다 → 느리게 눈만 깜빡인다")은 좋은 방식이라 문제로 세지 않아요. `### IDENTITY` 같은 대문자 제목도 강조어로 세지 않아요.
- **자동 테스트**에 "재미 포인트 자극" 유형이 생겼어요. 트리거, 개그, 속마음을 건드려 봐요.

## 패널 조작

- **옮기기**: 패널 윗부분(제목줄)을 마우스나 손가락으로 끌면 돼요. 위치는 저장돼요.
- **접기/펴기**: ➖ 버튼, 또는 제목줄을 더블클릭하면 돼요. 접은 상태에서도 진행 상황이 제목줄에 보여요.
- **가로 폭 조절 (PC)**: 패널 오른쪽 아래 모서리를 끌면 폭을 넓히거나 줄일 수 있어요. 조절한 폭은 저장돼요.
- **위치 초기화**: ◎ 버튼. 패널이 화면 밖으로 나가서 버튼이 안 보이면 채팅창에 `/bottest-reset`을 입력하거나 Extensions 패널의 **패널 위치·크기 초기화** 버튼을 누르세요. `/bottest-close`로 바로 닫을 수도 있어요.
- 모바일에서는 테스트하는 동안 패널이 자동으로 접혀서 채팅이 가려지지 않아요. 끝나면 다시 펼쳐져요.

## 설정 팁 (⚙️ 설정 탭)

- **강조 색**: 샴페인 골드(기본) · 라벤더 · 세이지 · 로즈 · 아이스 블루 · 테마 색 따르기 중에서 고를 수 있어요. 패널 배경과 글자색은 SillyTavern 테마(밝은/어두운)를 자동으로 따라가요.

- **메시지 작성 방식** (테스트 탭)
  - ⚡ 빠르게: 테스트 메시지 전체를 AI 호출 한 번으로 미리 만들어요 (기본값).
  - 🐢 자연스럽게: 매 턴 봇 답장을 읽고 다음 메시지를 써요. 대화 흐름은 더 자연스럽지만 턴마다 AI를 한 번씩 더 불러서 느려요.
- **테스트 메시지 최대 토큰**: 테스트 메시지가 중간에 잘리면 늘려주세요. Gemini처럼 생각(reasoning)하는 모델은 생각하는 데도 토큰을 써요.

- **테스터용 연결 / 평가용 연결**: SillyTavern의 *Connection Profiles(연결 프로필)* 중에서 고를 수 있어요.
  봇은 평소 쓰는 모델로 돌리고, **평가는 더 똑똑한 모델**(예: Claude, GPT 상위 모델)로 시키면 점수가 훨씬 믿을 만해요.
  비워두면 지금 연결된 API를 그대로 써요.
- **평가 최대 토큰 / 프로필 최대 토큰**: 기본 16000이에요. 그래도 잘리면 32000 이상으로 올려주세요. 모델이 받지 않는 값이면 자동으로 낮춰서 다시 요청해요.
- **원작 자료 최대 글자 수**: 모델 컨텍스트가 작으면 줄이세요. 긴 위키 문서는 필요한 부분만 남기는 게 좋아요.
- **응답 언어**: 기본 한국어. 일본어 봇이면 `日本語`로 바꾸면 테스트 메시지·피드백이 일본어로 나와요.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 나무위키 링크가 “자동 수집을 막았어요”라고 실패 | 나무위키는 봇 차단이 강한 편이에요. 페이지 내용을 드래그 복사해서 원작 자료 칸에 직접 붙여넣어 주세요. |
| 링크 불러오기가 전부 실패 | SillyTavern 서버가 외부 인터넷에 접속 가능한지 확인해 주세요 (로컬 설치면 보통 OK). |
| 점수가 이상하게 짜거나 후함 | 평가용 연결을 더 큰 모델로 바꾸고, 원작 자료에서 관련 없는 내용을 정리해 보세요. 점수는 AI 판단이라 ±10% 정도 흔들릴 수 있어요. 같은 조건으로 2~3번 돌려 평균을 보는 걸 추천해요. |
| 기다리는 시간이 너무 김 | 테스터용 연결에 생각(reasoning)을 끈 빠른 모델 프로필을 지정하고, 작성 방식은 ⚡ 빠르게로 두세요. 대부분의 시간은 봇 답장 생성 시간이에요. |
| 테스트 메시지가 봇 대사까지 써버림 | 테스터용 연결을 지시를 잘 따르는 모델로 바꿔보세요. |
| 패널이 안 보임 | F12 → Console에 `[BotTester]` 로 시작하는 빨간 에러가 있는지 확인해 주세요. |

> ⚠️ 원작 자료와 대화 로그가 평가용 AI(API)로 전송돼요. 평소 쓰는 API와 같은 곳으로 가지만, 참고해 주세요.
